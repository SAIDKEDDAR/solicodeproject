# Sprint 5 : Afficher les articles du blog avec PHP

**Objectif :** Afficher une liste d'articles sur la page d'accueil avec PHP.

## Les tâches

| Étape | Action | Fichier | Terminé quand |
|-------|--------|---------|---------------|
| 1 | Créer la liste des articles | `data/articles.php` | `$articles` contient 3 articles. |
| 2 | Créer une fonction pour afficher un article | `includes/functions.php` | La fonction retourne l'article en HTML. |
| 3 | Afficher tous les articles sur la page | `index.php` | La boucle `foreach` fonctionne sans erreur. |
| 4 | Tester la page | Navigateur web | Les 3 articles s'affichent avec leur titre et leur résumé. |

## Vérification finale
L'étape 4 est le test : j'ouvre le navigateur et je vérifie que les 3 articles s'affichent sans erreur.
